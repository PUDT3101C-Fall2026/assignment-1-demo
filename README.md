# Assignment 1 Demo

Here is an example of how you can set up a repository for your Assignment 1 project, based on the examples I've created in class. _Note: This example is incomplete, because I don't have three pages!_

## Project README

Your assignment should contain a `README.md` file that contains some information about your project. The project overview shouldn't be very long, but good things to include would be:

- A one- or two-sentence description of how you intend for your project to work.
- A description of any specific technologies (Web features, APIs, libraries) you used beyond the main ones discussed in class.
- A brief description of the project organization (this doesn't need to cover everything, just any interesting files).

## AI Tools or Other Resources

**If you use AI tools or other resources, you should include a description of those in your `README` file!**

For AI tools, briefly describe what tool (Claude, Codex, Gemini, etc) and how you used it (chat, coding agent, etc). In addition, share some information about specific prompts you used, which pieces or phases of the project you primarily used it for, and any reflections you have about what ways it was (or wasn't) useful.

If you use other resources (such as online tutorials), include links to the tutorials and mention which pieces of the project the tutorials helped you develop. If you can include a note about what parts of the tutorial or guide were especially helpful (or confusing), that can help me identify potential resources for other students.
